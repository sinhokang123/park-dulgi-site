# park-dulgi-site

Public support / privacy site for **박둘기: 과적 배달왕** (Pigeon Overload, `com.parkdulgi.delivery`), served by GitHub
Pages from the `docs/` folder of `main` at https://sinhokang123.github.io/park-dulgi-site/. Only `docs/` is published;
templates, tooling and config stay out of the site.

| Path | What |
|------|------|
| `templates/*.html` | Page sources (Korean + English on one page, toggle via `#ko` / `#en`). Edit these. Not published. |
| `docs/` | **The published site** (Pages source: `main` / `docs`). |
| `docs/index.html`, `docs/privacy.html`, `docs/support.html`, `docs/app-ads.txt` | Generated by `fill.mjs`. Do not edit by hand. |
| `docs/assets/` | CSS, the language toggle script, icons (resized from `park-dulgi/docs/store/graphics/`), and a Jua subset (OFL, see `docs/assets/fonts/Jua-OFL.txt`). |
| `fill.mjs` | Fills `{{CONTACT_EMAIL}}`, `{{LEGAL_ENTITY}}`, `{{PRIVACY_OFFICER}}`, `{{EFFECTIVE_DATE}}` and the AdMob publisher id. |
| `site.config.json` | Manual overrides (public, so no secrets) and store URLs once the apps are live. |
| `user-site/` | Content for the separate `sinhokang123.github.io` repo: AdMob only crawls `app-ads.txt` at the domain root. |

```sh
node fill.mjs            # fill what is known; missing values stay as visible {{TOKENS}}
node fill.mjs --strict   # exit 1 while a page still has a {{TOKEN}} (run before every publish)
node fill.mjs --strict-ads  # also require the AdMob publisher id in app-ads.txt
```

Values come from `site.config.json` (non-empty wins) and then `../park-dulgi-ops/result.json`
(`play.contactEmail`, `asc.teamName` or `play.developerName`, `admob.publisherId`). The privacy officer defaults to the
legal entity. Publishing steps, URLs and store-console fields: `park-dulgi/docs/release/site.md`.

Headings use a subset of the Jua font. If you add heading text with new Hangul syllables, rebuild it from the game repo:

```sh
python3 -m fontTools.subset ../park-dulgi/public/fonts/Jua-Regular.ttf --text-file=<chars.txt> \
  --flavor=woff2 --layout-features='*' --output-file=docs/assets/fonts/jua-subset.woff2
```
where `chars.txt` holds every character used in `h1`/`h2`/`h3`, the brand name, both app names and printable ASCII.

Icons are resized from the game's brand export; re-run after `tools/brand/export.mjs` changes the app icon:

```sh
G=../park-dulgi/docs/store/graphics; A=docs/assets
cp $G/play-icon-512.png $A/icon-512.png
sips -z 192 192 $G/app-store-icon-1024.png --out $A/icon-192.png
sips -z 180 180 $G/app-store-icon-1024.png --out $A/apple-touch-icon.png
sips -z 48 48 $G/app-store-icon-1024.png --out $A/favicon.png
sips -z 400 400 -s format jpeg -s formatOptions 85 $G/app-store-icon-1024.png --out $A/icon-400.jpg
```
